Help

A quick guide to the main controls. Most everyday actions are available directly from the three main screens.

Repertoire

Repertoire is your complete song library. Search by title or use Category to show one band or project.

⋯ Category menu — rename a category or clear all songs from it. An empty category can also be deleted.

+ / ✓ adds a song to Current Set or removes it. Tap the Key to change it; the key is optional. Drag ≡ to change song order.

Press and hold a song title to edit its title, duration or category. Swipe right to reveal Delete.

Add song adds one song manually. Add songs as a list lets you paste several songs at once.

Deleting a song removes it from Repertoire, Current Set and all Saved Sets.

Current Set

Current Set shows the set you are working on, including song count and total duration. Drag ≡ to reorder songs, tap − to remove one, tap a key to change it, or press and hold a song title to edit its details.

The name above the songs is the Saved Set currently open. ★ Favorite marks that Saved Set as a favorite.

Undo / Redo steps backward or forward through recent changes. Clear current set removes all songs from Current Set.

Update current set overwrites the Saved Set currently open. Changes are not saved automatically.

Share / Copy set list exports a simple text list. Save current set creates a new Saved Set with the name and category you choose.

Saved Sets

Saved Sets stores your set lists. Tap a set name to open it in Current Set. Each row shows song count and total duration; ★ marks a favorite.

Category filters Saved Sets independently from Repertoire categories. ⋯ Category menu renames a category or clears it; an empty category can also be deleted.

Press and hold a set name to rename it or change its category. Copy copies it as text, Share opens the system share sheet, and Delete removes it.

Undo last change restores the most recent Saved Sets change when available.

Backup / Restore exports or restores your songs, categories, Current Set and Saved Sets.
